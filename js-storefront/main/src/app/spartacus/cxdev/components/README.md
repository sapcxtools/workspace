# Components

Hier werden alle Komponenten angelegt, die nur reine Angular Komponenten sind und von mehreren Feature Modules verwendet werden können.
Komponenten die keine CMS Komponenten sind, aber nur von einem bestimmten Feature Module benutzt werden, müssen auch in diesem Module angelegt werden und nich hier.

Es gibt kein gesondertes Module für die Komponenten, da alle Komponenten standalone generiert werden sollten.

`ng g c cxdev-[COMPONENT_NAME]`
